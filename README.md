## Overview
- **Role:** AI Ecommerce Creative Designer
- **Product:** Purifying Gel Cleanser (Neem & Green Tea • 100ml / 3.38 fl. oz.)

- **Interactive High-Res Lightbox:** Full asset inspector with keyboard navigation (`←` / `→`) and detailed placement notes.
